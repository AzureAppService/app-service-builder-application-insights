# Contributing

This project welcomes contributions and suggestions. Most contributions require
a Contributor License Agreement; see https://cla.opensource.microsoft.com.
The CLA bot will explain any required action on your pull request.

Follow the [Microsoft Open Source Code of Conduct](.github/CODE_OF_CONDUCT.md).
Open a focused pull request with the validation commands and results from README.md.
Changes to main require passing CI and an independent code-owner approval.
Do not disable telemetry redaction, identity authentication or demo bounds to
work around a test failure. Tests must not send telemetry to Azure.

Never include credentials, connection strings, user payloads or private deployment
records. Report vulnerabilities privately as described in SECURITY.md.
